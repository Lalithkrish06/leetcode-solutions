## 👨‍💻 About This Repository

This repository documents my **Data Structures & Algorithms journey through LeetCode**, with solutions primarily implemented in **Java**.

The goal is not simply to collect accepted solutions, but to develop the ability to:

* 🧠 Break complex problems into smaller parts
* ⚙️ Choose appropriate data structures and algorithms
* 📊 Analyze **time and space complexity**
* 🔍 Identify patterns behind problems
* ✨ Write clean, readable and maintainable Java code
* 🎯 Prepare systematically for technical interviews

> **Solve → Understand → Optimize → Repeat.**

## 📊 Complexity Matters

For every solution, I aim to understand:

```text
⏱️ Time Complexity
💾 Space Complexity
🧠 Algorithmic Pattern
⚡ Optimization Opportunities
```

Example:

```java
// Brute Force
Time  : O(N²)
Space : O(1)

// Optimized using HashMap
Time  : O(N)
Space : O(N)
```

The objective is to understand **why the optimized solution works**, not just memorize the code.
