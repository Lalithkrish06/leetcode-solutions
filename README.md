# 📖 About This Repository

This repository documents my **Data Structures & Algorithms journey through LeetCode**, with solutions primarily implemented in **Java**.

- ☕ Writing clean and readable Java code

# 📊 Complexity Analysis

Understanding complexity is a core part of this journey.

For each solution, I aim to identify:

| Metric | Focus |
|---|---|
| ⏱️ **Time Complexity** | How runtime grows with input size |
| 💾 **Space Complexity** | Additional memory requirements |
| 🧠 **Algorithmic Pattern** | Reusable strategy behind the solution |
| ⚡ **Optimization** | Opportunities to improve the approach |

### Example

```java
// Brute Force
Time  : O(N²)
Space : O(1)

// Optimized using HashMap
Time  : O(N)
Space : O(N)
```

The goal is to understand **why the optimized approach works and when it should be used**, rather than memorizing code.
